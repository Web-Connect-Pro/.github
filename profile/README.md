## About

Web Connect Pro is a Dutch web development and hosting company specialising in
Joomla-based websites, domain hosting, and custom web solutions. Through a broad
portfolio of client projects we have built up extensive experience across the
full web stack — from infrastructure and hosting to bespoke extension
development and end-user support.

We are a reseller of Vimexx hosting services and combine that with our own
in-house development capacity to deliver end-to-end solutions.

## What we do

- **Web hosting & domain management** — managed hosting for small and
  medium-sized organisations, with the underlying infrastructure fully taken
  care of.
- **Joomla website development** — design, build, and restyling of responsive
  Joomla sites tailored to the customer's brand and business processes.
- **Custom Joomla extensions** — in-house components, plugins, and modules
  distributed through our own release system (WCPRS) on
  `webconnectpro.nl`.
- **Identity & single sign-on** — OIDC-based SSO integrations (Microsoft Entra
  ID, Nextcloud) and a full Joomla-native Identity Manager (JML lifecycle,
  role-based authorisation, approvals, self-service).
- **API integration** — a REST endpoint framework for Joomla (API Manager)
  enabling controlled, authenticated data exchange with third-party systems.
- **Vendor extension rebranding** — repackaging third-party Joomla extensions
  so updates flow through our release channel, giving customers a single
  update source.
- **Ongoing support & maintenance** — content-management freedom for the
  customer with infrastructure worries handled by us ("ontzorging op maat").

## Open-source presence

This GitHub organisation hosts the source of our own Joomla 6 extensions and
supporting tooling, including:

- **API Manager** — REST endpoint framework (component + module + router
  plugin + scheduler plugin).
- **WCP Release System (WCPRS)** — package distribution, streams, DLID
  authentication, and updater feed.
- **WCP Identity Manager** — Joomla-native IAM (JML lifecycle, RBAC,
  approvals, self-service).
- **Entra ID SSO** — OIDC single sign-on plugin against
  `login.microsoftonline.com` (PKCE by default).
- **Nextcloud SSO** — OIDC single sign-on plugin against the Nextcloud OIDC
  provider app.

All extensions ship bilingually (en-GB + nl-NL) and target modern Joomla 6 on
PHP 8.2+.
